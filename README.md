# AI-Women-Safety-Smart-Slipper
AI-based wearable safety slipper for real-time panic detection, emergency alerts, and live location tracking using IoT and embedded systems.

🚨 Problem Statement

Women often face safety risks during emergencies, especially when they are unable to access mobile phones quickly. Existing safety systems mainly depend on manual activation, leading to delayed response and reduced effectiveness in critical situations.

✨ Features
Automatic panic detection using AI
Real-time GPS location tracking
Emergency SOS alert system
GSM-based emergency calling and messaging
Wearable and hands-free safety device
Buzzer and LCD alert indication



🔧 Hardware Components
ESP32 / Arduino Microcontroller
Heart Rate Sensor
Temperature Sensor
Accelerometer (MPU6050)
GPS Module
GSM Module
LCD Display
Buzzer
Rechargeable Battery


⚙️ Working Principle

The sensors continuously monitor the user’s heart rate, temperature, and movement patterns.
The microcontroller processes this data using AI-based logic to detect abnormal or panic conditions. 
When danger is detected, the system automatically sends SOS alerts and live location to emergency contacts through GPS and GSM modules while activating local alerts using a buzzer and LCD display.
